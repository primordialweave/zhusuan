## 全局审查与修复

审查覆盖登录与鉴权、项目/收款业务、日历与统计、导出、设置管理、数据迁移、安装更新、版本工具和 CI。对确认的问题进行了窄范围修复及行为验证；这是发布准备审查，并非逐行安全认证。

| 问题 | 修复和验证范围 |
| --- | --- |
| 负数、零和非有限金额可写入账目 | DTO 与服务层拒绝；确认款项/项目创建及更新回归验证 |
| 显式 overdue 从待收与逾期统计消失 | 统一状态集合；全量/期间统计验证 |
| 结束日完整时间戳漏选，SQLite 带时区日期跨日 | 采用下一日半开区间与存储日期分量；跨时区日/月趋势回归 |
| 合同金额改变后旧款项比例未更新 | 合同和比例同事务更新；注入失败验证全部回滚 |
| 同一项目多个款项写入可能覆盖汇总 | 创建、修改、确认、删除及项目删除统一先锁父项目；SQLite 并发与 MySQL FOR UPDATE SQL 验证，未实测 MySQL/Pg 并发 |
| 数据库鉴权查询失败回退旧 Token 权限 | 返回 503 且不把临时错误缓存成账号禁用 |
| 第二次会话过期失效、旧异步请求覆盖新会话 | 按发起 Token 处理结果和过期去重；暂时网络错误保留登录 |
| 收款选择只覆盖前 100 个项目 | 固定项目 GET，通用选择器按需搜索/20 项分页 |
| 详情加载失败永久骨架，编辑失败可误保存 | 路由对应加载状态、禁止保存与页内重试 |
| 多请求部分成功后重试重复已成功记录 | 保留已确认成功的 ID/删除结果和输入，跳过未修改的成功项；保存中继续编辑回归 |
| CSV 引号不能阻止公式执行 | 对危险字符串前缀增加文本转义，数值金额保持原数值 |
| WebView2 安装失败仍可能报成功 | 项目自有 NSIS 门禁检查退出码并复查运行时，替换程序前失败；隔离编译通过，失败下载实机未验 |
| 原生/移动版本遗漏与 MSIX 最低版本误改风险 | 统一同步并新增元数据/无部分写入回归，最低系统字段独立保留 |

独立 Gosec 的原始 SARIF 有 16 条模式提示：G703×1、G204×2、G304×10、G117×1、G706×2。已核对固定用户缓存、迁库/暂存/profile 文件路径、固定 dpkg-query/rpm 参数、写入系统凭据的登录 JSON 及本机环境日志地址；保留报告供继续审查，不把变量路径或秘密字段模式当作已复现远程漏洞，也不把成功 job 当作无漏洞认证。

## 发布前仍需的目标平台验收

- Windows：真实 Orange 自定义目录升级、新身份首次启动迁库、标准用户/UAC、WebView2 无网络/下载失败、成功更新后以原用户重启。现有 smoke 脚本在 Release runner 执行；本次未触发发布流程。
- macOS：正式 bundle 的签名/公证策略、旧系统兼容性、原生保存对话框和真实已安装应用更新。现有 SDK 对较低部署目标有链接提示，不能从当前机器构建推断旧系统可运行。
- Linux：AppImage、deb/rpm 的实际安装与提权、包归属和重启。MySQL/PostgreSQL 的真实并发事务及云同步对比/同步另需集成环境。
- 更新回滚覆盖文件替换失败和系统拒绝启动；系统接受启动后，新进程初始化或数据库迁移失败没有启动健康确认与自动回滚。
- 项目加多笔计划仍为多个 API 请求。当前账本只去重收到成功响应的结果；服务端提交但响应丢失、页面卸载/退出后重试仍可能产生重复，须核对记录。完整解决需服务端原子或幂等接口，当前文档不承诺恰好一次保存。
- 性能验收需记录目标设备启动时间、内存与空闲/动态场景 CPU/GPU；更新需核对大包峰值内存。实现已有场景帧率/像素预算、后台暂停、资源释放、20 项按需分页和流式摘要控制，本次未作原生电池/性能基准。

上述边界应在真正发版前逐项确认。iOS/Android 仅同步脚手架与资源，不作为本次已验收发布平台。
