# 珠算 1.4.0 发布验证

本次发布包含当前全部产品改动：原生桌面常驻、开机启动、菜单栏速览、全局快捷键、提醒和本地快照，六套四季/节庆主题，项目状态多选与设计系统示例，以及资料/通知回显、输入和全局审查修复。

## 发布前修正

- 修复隐藏窗口在异步场景初始化期间丢失 hide 状态；冷静默启动使用现有 GetState 的 windowHidden，不新增启动调用或轮询。原失败探针复测2/2通过，场景/状态控制55/55通过。
- Linux安装包和AppImage使用应用自有桌面模板，保留三个快捷操作；Python49/49通过。
- Go新增代码的全部常量/复杂度提示已修复，Wails接口/持久字段命名保留精确兼容规则；发布范围golangci为0，不调整真实CI基线。
- Windows权限位夹具保留内容/原子性验证，POSIX0600断言仅在适用平台运行；不把WindowsMode当ACL验收。
- Wails取得单实例锁后才启动外部API端口，避免第二实例先遇到端口冲突。
- 草稿附件公开前核对名称、大小和GitHub服务端digest；最终下载继续用SHA256SUMS/update.json核验。

## 原生关闭与通知分页补充

Windows复验45157183979通过了不可变基线与同路径升级，但明确quit关闭策略仍留下常驻进程，暴露了应用真实缺陷：最后窗口关闭的自动退出被禁用，BeginQuit仅设置状态。现在关闭路径取消当前事件并显式RequestQuit；退出/托盘不可用两种策略先RED后通过本地race回归，仍需新原生候选验证。
