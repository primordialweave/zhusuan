## 采集说明

按本次用户要求，**截图不打码，不替换或遮挡页面中的项目、客户、合同、备注、作者及联系信息**。项目名称 `Mock 项目 001–077` 与客户 `will` 是账本在本次采集前已有的内容，并非采集时脱敏处理。

采集使用独立数据库副本，未修改源账本；浏览器主题偏好仅写入本任务的预览地址。登录页保持空输入，不展示密码或令牌。等待数据、图片与页面入场动画完成后再截图。

浏览器预览用于展示实际界面，不作为 Wails 原生文件保存、系统凭据存储、桌面图标或安装更新能力的验收证据。旧版截图与验收记录保留在各自子目录中，本表仅描述本次替换的 README 图片。
