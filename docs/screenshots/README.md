## 脱敏范围

截图使用独立数据库副本。采集前已将项目名称、客户、合同编号、项目说明、收款备注、人员姓名、邮箱、电话、部门、职位、通知文本及令牌名称等敏感字段替换为黑块，头像清空。合同编号使用无原始信息的唯一后缀，满足数据库唯一约束。原用户数据库不作修改。

项目总额、已收金额，以及每笔收款的金额与比例均与源数据逐项核对，保持不变。类型、日期、统计范围及通用字典项保留，用于呈现实际界面。

关于页中硬编码的个人介绍、作者和联系方式在截取时通过页内遮挡处理；珠算名称、公开仓库地址与版本号保留。登录截图不填账号或密码。原始未脱敏截图不进入本目录或应用静态资源。

后续更新截图时仍应先脱敏隔离数据，再逐页检查姓名、合同、备注、联系信息及弹层。金额无需打码。页面截图应来自最新构建，不用运行中的旧预览进程替代新代码验证。
